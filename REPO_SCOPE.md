# Repository scope

This is the single aggregated reproduction repository for the OBS/BHP thesis.

- `nobs/`: modified nOBS/ns-2 source required by the experiments.
- `experiments/`: versioned experiment runners, validators, parsers, analysis and tests.
- `evidence/direct_bhp_matrix/`: compact canonical metadata/statistics; raw traces are intentionally excluded.
- `deliverables/`: final DOCX/PDF artifacts.

The native direct-BHP matrix is reproduced/validated at 32/32 cells. ML/UCI material is retained as audited scope only unless its raw source and protocol are present; no unavailable artifact is presented as reproduced.
